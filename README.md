## Overview

This project demonstrates an end-to-end DevSecOps and GitOps pipeline using Jenkins, Docker, SonarQube, Kubernetes, and security-focused automation.

## Project Structure

- `website/` - Frontend project website with profile, resume, and project presentation
- `images/` - Screenshots and visuals used in the README
- `Dockerfile` - Docker image build configuration
- `Jenkinsfile` - Jenkins CI/CD pipeline definition
- `main.yml` - Kubernetes manifest for deployment
- `sonar-project.properties` - SonarQube project configuration
